# 图床

登录后在顶部选择「图床」。图片原件存储在当前 Telegram 频道，VPS 保存外链和文件元数据并转发图片。

## 使用

- 点击上传、拖入图片，或在图床页面粘贴剪贴板图片，支持批量上传。图片传到 VPS 的途中断开后，重新上传会从头开始。
- 支持 JPEG、PNG、GIF、WebP，单张最大 20 MiB；服务端校验文件头。
- **在图床上传即公开发布**。上传完成后选择「获取链接」，复制直链、Markdown 或 HTML 引用。
- 「从网盘添加」可发布已有图片。普通网盘上传不会自动发布。
- 「撤销外链」立即使原链接失效，保留网盘原件；再次发布会生成新链接。
- 删除网盘原件也会使外链失效。第三方已自行下载的副本无法撤回。
- 频道同步检测到媒体被替换时自动撤销该图片外链。频道导入图片仅修改简介或名称不影响链接；网页上传图片对应的 Telegram 消息发生任何编辑时会保守撤销外链，需要重新发布。

管理界面需要登录，持有随机外链的人可以匿名读取图片。外链按当前频道隔离；切换存储频道后，原频道的链接暂不可用，切回后恢复。

图片读取仍经过 Telegram → VPS → CDN → 访问者，遵循现有 CDN 配额保护。图床不会将私有频道整体公开，也不会绕过配额限制。

## 反向代理和 CDN

`/i/*` 必须绕过共享缓存、保留 `Range` / `206` 和响应类型，不能强制缓存。应用返回 `private, no-store` 及 `Cloudflare-CDN-Cache-Control: no-store`，随仓库提供的 Caddy 配置也包含此路径。已有代理需遵循这些响应头，否则撤销效果可能受缓存影响。

## API

| 方法与路径 | 行为 |
| --- | --- |
| `GET /api/images?q=&limit=24&offset=0` | 已发布图片，支持名称搜索及分页，需要登录 |
| `POST /api/images/{item_id}` | 校验并发布已有图片，需要登录；重复调用保留原链接 |
| `DELETE /api/images/{item_id}` | 撤销外链，需要登录 |
| `GET /i/{token}`、`HEAD /i/{token}` | 匿名图片直链，支持范围读取 |

创建上传任务时向现有 `POST /api/uploads` 传入 `image_host: true`，后续沿用分片上传、完成和进度接口；后台写入 Telegram 成功后自动发布。发布意图保存在数据库中，刷新页面不会丢失。

数据库从版本 10 自动迁移至 11，新增图床外链表和上传用途字段。部署前备份所有频道的 SQLite 数据库，旧版本程序无法直接打开升级后的数据库。
