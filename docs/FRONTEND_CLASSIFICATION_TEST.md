# 前端与自动分类验证

日期：2026-11-04，Asia/Shanghai。

## 实现

- 服务端统一分类：图片、视频、音频、文档、压缩包、代码、安装包、其他。
- 已知扩展名优先，MIME 类型作为补充；新文件和重命名均更新分类。手机通用 MIME 值在可能时补齐具体类型，用于浏览器预览。
- 分类聚合所有文件夹，保留原有目录；历史文件由 schema v2 事务迁移补齐分类。
- 分类导航、数量与体积统计、跨目录/目录内搜索、排序、分页、列表和网格视图。
- 移动端分类导航和文件操作菜单，PDF/图片/音视频预览与格式不支持提示。
- 弹窗标题关联、键盘焦点管理、背景滚动锁定和长文件名窄屏约束。

## 自动检查

- 后端：53 项测试通过，覆盖率 82.85%；Ruff 检查与格式检查通过。
- 前端：9 项 Node 测试通过；TypeScript 类型检查与 Vite 生产构建通过。
- 新增覆盖：v1 数据迁移、迁移失败事务回滚、旧数据分类、手机/电脑上传、通用 MIME、跨目录分类、重命名、搜索字面字符、分页排序、异步请求过期响应保护。

## 浏览器验证

在临时数据库和模拟存储上验证：桌面列表/网格、分类切换、分页、搜索与清空、空状态、文件夹上传后跨目录分类可见、重命名后重新归类、弹窗焦点和滚动锁定。

布局检查宽度：320、375、390、768、1024、1280、1440 像素，均无页面横向溢出。桌面与手机截图采用临时演示数据，未写入正式网盘。

## 真实 Telegram 验证

通过本机网页实际上传一张有效 PNG，并将浏览器 MIME 设置为 application/octet-stream，验证完整链路：网页 → FastAPI → 已配置的私有 Telegram 频道 → 服务端归入图片 → 390px 手机尺寸分类页 → 真实图片预览 → 下载 SHA-256 一致。

长文件名的手机预览弹窗关闭按钮已断言在视口内，且可以正常点击。测试文件及对应上传记录已通过应用 API 删除，删除接口未返回 Telegram 清理警告。

## 范围

手机检查使用浏览器移动尺寸模拟，未在实体手机上逐一验证浏览器兼容性。分类依据文件格式，不执行文件内容识别、格式转换或 HEIC 转码。
